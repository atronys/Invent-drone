# hardware — CAD, схемы, фото сборки

Состав и выбор компонентов — [docs/05_hardware_bom.md](../docs/05_hardware_bom.md).

Структура по мере работы:
- `cad/` — крепления камер и подсветки, защита винтов, док (3D-печать);
- `wiring/` — схема питания и подключений (ПК ↔ компаньон по UART/Ethernet, камеры, строб);
- `logs/` — отчёты о полётах (шаблон — FLT-06), вибрации, энергобюджет (HW-08).
