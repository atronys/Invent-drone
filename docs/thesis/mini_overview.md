# Мини-обзор проекта ВКР

**Рабочая тема:** «Разработка системы автономной инвентаризации паллетного склада с использованием БПЛА».
**Ядро новизны:** метод локализации БПЛА в помещении склада по штатным складским этикеткам с известными координатами.

## Проблема

На паллетных складах инвентаризацию делают вручную: оператор на ричтраке поднимается к каждой ячейке
на высоту до 10–12 м и сканирует этикетки. Это медленно (десятки секунд на ячейку), дорого, опасно
и часто требует остановить работу склада. Поэтому пересчёты делают редко, а расхождения между учётом (WMS/1С)
и фактическим наличием копятся месяцами. Зарубежный аналог — Corvus Robotics (США). В России похожими
задачами занимается UVL Robotics; массового продукта для средних складов нет.

## Что я хочу сделать

Дрон, который **сам** облетает проходы между стеллажами по плану склада, считывает камерами штрихкоды
паллетных и адресных этикеток, привязывает каждое чтение к адресу ячейки и сверяет результат с выгрузкой
из WMS/1С. Итог работы системы — отчёт о расхождениях: «всё сходится», «не та паллета», «ячейка пуста»,
«лишняя паллета», «этикетка не читается».

Без GPS и без дорогой инфраструктуры в здании: навигация по визуально-инерциальной одометрии
с коррекцией по этикеткам, которые на складе уже висят (адрес ячейки на балке стеллажа = ориентир
с известными координатами).

## Задачи работы

1. Анализ процессов инвентаризации и существующих решений.
2. Модель склада и постановка задачи облёта с ограничением по заряду АКБ (orienteering problem); планировщик вылетов.
3. Привязка считанной этикетки к ячейке по 6-DoF позе камеры; методика выбора оптики (разрешение, объектив,
   выдержка) под размер штрихкода и скорость полёта.
4. **Метод локализации по этикеткам** (расширенный фильтр Калмана поверх VIO, наблюдение — пиксель этикетки).
5. Реализация: ROS 2 + PX4, симуляция в Gazebo, сервер сверки; эксперименты в симуляции → на стенде → на складе.
6. Экономическая оценка и требования безопасности полётов в помещении.

## Что уже сделано (октябрь 2026)

- Программное ядро: модель склада, планировщик облёта, модель камеры, привязка к ячейкам, сверка с WMS (тесты).
- Виртуальный облёт всего конвейера (рендер кадров → чтение кодов → сверка) и эксперименты:
  - локализация по адресным этикеткам даёт ошибку **2–6 см** против 30–74 см при метках только на торцах рядов;
  - ошибка позиции 30 см приводит к неверной привязке ~13% ячеек — точность навигации напрямую определяет
    точность инвентаризации;
  - EKF не уступает по точности оптимизации в скользящем окне при затратах в 60–70 раз меньше;
  - расчёт оптики: нужна камера ~12 Мп в портретной установке, выдержка ≤ 1 мс.
- Узлы ROS 2 (миссия, чтение этикеток, локализация, безопасность), модель дрона и мира для Gazebo,
  матрица аварийных режимов. Идёт перенос в симуляцию PX4 SITL; железо — следующий этап.

## Ожидаемые результаты и метрики

Работающий прототип (симуляция + лабораторный стенд + пилот на складе); метрики: доля прочитанных этикеток,
точность привязки к ячейкам, ошибка локализации (ATE), ячеек в час, найденные расхождения; юнит-экономика
в сравнении с ручным пересчётом. Возможен формат «Стартап как диплом».
