# SAFE-03: матрица аварийных режимов и параметры PX4 для полётов в помещении

Имена, значения по умолчанию и допустимые значения параметров сверены с исходниками **PX4 v1.17.0**
(`src/modules/commander/commander_params.c`, `navigator/geofence_params.c`, `navigator/rtl_params.c`,
`mc_pos_control/*_params.c`, `ekf2/module.yaml`) 28.09.2026. Файл для загрузки — `sim/px4_params_indoor.txt`.

## Почему заводские значения не годятся для склада

| Параметр | По умолчанию | Проблема в проходе склада | У нас |
|---|---|---|---|
| `RTL_RETURN_ALT` | 60 м | «Возврат» набирает 60 м — удар о потолок и сплинклеры | 1.5 м, а действия «Возврат» не используем вовсе |
| `MPC_XY_VEL_MAX` / `MPC_XY_CRUISE` | 12 / 5 м/с | Проход 3 м, стеллажи с двух сторон | 1.5 / 1.0 м/с |
| `MPC_Z_VEL_MAX_UP` / `_DN` | 3 / 1.5 м/с | Балки ярусов над и под дроном | 1.0 / 0.7 м/с |
| `MPC_YAWRAUTO_MAX` | 60 °/с | Резкий разворот срывает VIO (статья A, сценарий 4) | 30 °/с (= `ScanParams.yaw_rate_deg`) |
| `COM_POS_FS_EPH` | 5 м | Ошибка позиции 5 м в проходе 3 м — это уже в стеллаже | 1.0 м |
| `COM_OBL_RC_ACT` | 0 (Position) | Узел миссии упал, пилота нет — Position mode без стиков бесполезен | 4 (Land) |
| `COM_LOW_BAT_ACT` | 0 (только предупреждение) | Дрон продолжит лететь на критическом заряде | 2 (Land) |

## Матрица событий

| Событие | Кто обнаруживает | Реакция | Настройка | Проверка в SITL |
|---|---|---|---|---|
| Препятствие по курсу (погрузчик, человек, коробка) | `safety_monitor` (depth, коридор, тормозной путь) | STOP: узел миссии замирает; снятие — после 5 чистых кадров | `core/invent_core/safety.py` | мир с `--obstacle`: стоп на ≥ 1 м |
| Выход из коридора прохода | `safety_monitor` (геозона из раскладки) | STOP | `Geofence` | сдвинуть уставку за коридор |
| Грубый выход за пределы склада | PX4 geofence (цилиндр от дока) | Land | `GF_ACTION=5`, `GF_MAX_HOR_DIST`, `GF_MAX_VER_DIST` | уставка за пределами |
| Узел миссии упал / поток Offboard пропал | PX4 commander | через 0.5 с — Land | `COM_OF_LOSS_T=0.5`, `COM_OBL_RC_ACT=4` | `kill` узла миссии |
| Потеря навигации (VIO/локализация упали) | PX4 EKF2 (нет внешней навигации) | позиция недействительна → Offboard недоступен → Land (без горизонтальной позиции — Descend) | `EKF2_EV_CTRL`, `EKF2_NOAID_TOUT` | `kill` узла fake_vio / landmark_localizer — только с выключенным GPS (SIM-05), иначе EKF держится на GPS |
| Растёт ошибка позиции | PX4 commander | Land | `COM_POS_FS_EPH=1.0` | большой дрейф VIO (`fake_vio` с `scale_err`) |
| Низкий заряд | узел миссии (бюджет вылета с резервом 25%) → PX4 на критическом уровне | план не допускает; PX4 — Land | `ScanParams.reserve`, `COM_LOW_BAT_ACT=2` | уменьшить `battery_s` |
| Потеря пульта (полёт с пилотом-страхующим) | PX4 | Land | `NAV_RCL_ACT=3`, `COM_RC_LOSS_T` | выключить пульт |
| Потеря пульта (полностью автономный полёт) | PX4 | игнорировать в Offboard | `COM_RCL_EXCEPT=4` (бит 2 — Offboard) | — |
| Потеря связи с сервером / Wi-Fi | — | игнорировать: вся автономия на борту | `NAV_DLL_ACT=0` | — |
| Человек в проходе | организационно (MVP): полёты без людей | — / SAFE-06 детекция людей | регламент LEGAL-02 | — |

Действие «Возврат» (Return) **не используется** ни в одном аварийном режиме: в PX4 это полёт по прямой
к дому, внутри склада он пройдёт сквозь стеллажи. Возврат к доку делает только узел миссии — по маршруту через
магистральный проезд.

## Геозона PX4 без GPS

`GF_SOURCE=0` (глобальная позиция). Без GPS глобальной позиции нет, пока не задано начало координат EKF.
На доке его нужно задать один раз: MAVLink `SET_GPS_GLOBAL_ORIGIN` или в консоли PX4
`commander set_ekf_origin <широта> <долгота> <высота>` (команда есть в `Commander.cpp` v1.17; координаты — любые
постоянные, например адрес склада). Иначе цилиндрическая геозона PX4 не работает, и остаётся только геозона
`safety_monitor`. Проверить в SITL с выключенным GPS (задача SIM-05).

## Как применяется

- **SITL:** `scripts/smoke_sitl.sh` после «Ready for takeoff» задаёт параметры из `sim/px4_params_indoor.txt`
  через `px4-param set` (итог — в `summary.txt`, подробности — `px4_params.log`). `PX4_PARAMS=none` — прогон
  с заводскими, `PX4_PARAMS=путь` — свой файл.
- **Реальный дрон:** тот же файл через QGroundControl → Parameters → Tools → Load from file (формат QGC другой —
  сконвертировать при появлении железа, задача FLT-04), затем проверка каждого пункта матрицы на привязи.

## Что ещё не проверено

Пункты матрицы выше — проектные решения, сверенные с описаниями параметров, **но не с поведением**: ни один
сценарий «Проверка в SITL» ещё не запускался (среда ROS 2 + PX4 в WSL ставится, ENV-02). Порядок проверки
после дымового теста: kill узла миссии → kill локализации → дрейф VIO → препятствие → геозона.
