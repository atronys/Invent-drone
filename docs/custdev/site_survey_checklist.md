# Чек-лист обследования склада (BIZ-06)

Это не формальность: цифры отсюда — входные данные для выбора камеры и объектива (PER-01),
раскладки (MIS-02), высот пролётов и безопасности. Взять: рулетку или лазерный дальномер,
линейку, люксметр (или приложение), телефон.

## 1. Геометрия (на 1–2 типовых прохода)

| Параметр | Значение | Как мерить |
|---|---|---|
| Ширина прохода (между фасадами), м | | Рулетка/дальномер у пола и на высоте |
| Длина прохода / число секций | | Счёт секций × ширина секции |
| Ширина секции, мест в секции | | Между стойками |
| Высоты балок (ярусы), м | | Дальномер от пола до верха каждой балки |
| Высота верхней балки и потолка, м; спринклеры, светильники | | Что мешает полёту над/у верха |
| Магистральный проезд: ширина, где свободно | | Для перелётов и дока |
| Препятствия в проходах (колонны, тележки, плёнка) | | Фото |

## 2. Этикетки — главное

| Параметр | Значение | Как мерить |
|---|---|---|
| Тип паллетной этикетки (SSCC GS1-128? QR? DataMatrix? своя?) | | Фото этикетки целиком |
| Размер этикетки, мм | | Линейка |
| **Ширина штрихкода (только штрихи, без полей), мм** | | Линейка — см. формулу ниже |
| Высота этикетки над балкой, м; сторона паллеты | | Рулетка |
| Адресные этикетки: где висят, размер, тип кода | | Фото + линейка |
| Состояние: плёнка поверх, блики, надрывы, % нечитаемых | | Фото с разных углов, со вспышкой и без |

**Ширина модуля штрихкода X** — от неё зависит выбор оптики. Для SSCC в GS1-128 ((00) + 18 цифр)
код содержит **156 модулей** (старт, FNC1, 10 пар цифр, контрольный символ — по 11 модулей, стоп — 13),
поэтому:

```
X, мм = ширина штрихов, мм / 156        78 мм -> 0.50 мм;  94 мм -> 0.60 мм;  125 мм -> 0.80 мм
```

Затем: `python -m invent_core optics --distance <половина ширины прохода> --hfov <угол> --vfov <угол>`.

## 3. Среда

| Параметр | Значение | Как мерить |
|---|---|---|
| Освещённость в проходе днём / ночью, лк (у пола и на верхнем ярусе) | | Люксметр |
| Температура, сквозняки (ворота, тепловые завесы) | | Спросить |
| Покрытие Wi-Fi в проходах | | Телефон, замер скорости |
| Окна без техники и людей (ночь, выходные, зона) | | Спросить |
| Место для дока и зарядки АКБ, розетка, пожарные требования | | Спросить инженера по ОТ/ПБ |

## 4. Данные

- Формат выгрузки остатков по ячейкам (CSV/Excel/1С), столбцы, кодировка — образец (DATA-01).
- Формат адреса ячейки (например, `ряд-секция-ярус-место`) → под него настроить `layout`.

## 5. Фото (с разрешения)

Проход целиком с торца; фасад крупно (3 яруса); 5–10 этикеток крупно рядом с линейкой; адресные
этикетки; место для дока. **Без людей в кадре.**
