# ml — данные и модели (Ф2–Ф4)

Для MVP нейросети не нужны: этикетки читает zxing-cpp, геометрия — из плана склада.
Понадобятся для:
- **PER-09** — детектор кандидатов этикеток (чтобы отличать «нет этикетки» от «не прочиталась»);
  лицензии только Apache/MIT (YOLOX, RT-DETR), **не Ultralytics (AGPL-3.0)**;
- **PER-08** — занятость ячейки (часто хватает depth + геометрии без обучения);
- **MIS-08** — исследовательский трек: PPO для адаптивного перескана по мотивам статьи A.

Данные: `datasets/sim` (из `sim/generate_world.py` + рендер Gazebo), `datasets/lab` (стенд PER-03),
`datasets/pilot` (с согласия склада, лица размыты). Большие файлы — не в git (DVC или облако вуза).
