# RackScan — стенд визуального сканирования стеллажей на Raspberry Pi

Отдельный проект внутри INVENT_DRONE: система съёма информации со стеллажа без привязки к дрону.
Камера на Raspberry Pi определяет стеллаж, полку и ячейку по адресным меткам ArUco, решает, занята
ли ячейка, находит и читает QR/штрихкод, подсказывает оператору, куда сместить камеру
(красный — выполняйте указания, жёлтый — держите ровно, зелёный — готово), сохраняет фото и журнал
и сверяет результат с учётом склада (эмулятор в терминах «1С:WMS Логистика. Управление складом»).

## Быстрый старт на ПК (без железа)

```bash
python -m venv .venv
```
```bash
.venv/Scripts/python -m pip install -r requirements.txt
```
```bash
.venv/Scripts/python -m rackscan selftest
```
```bash
.venv/Scripts/python -m rackscan run
```

После `run` откройте <http://localhost:8080>, нажмите «Начать инвентаризацию» и «Включить имитатор
носителя» — виртуальная камера сама выполнит команды стенда на синтетическом складе.

Тесты: `.venv/Scripts/python -W ignore -m unittest discover -s tests` (88 тестов).

## Состав

| Путь | Что это |
|---|---|
| `rackscan/optics.py`, `layout.py`, `markers.py`, `pose.py` | оптика, модель стенда, метки, поза камеры по PnP |
| `rackscan/codes.py`, `occupancy.py` | чтение кодов (zxing-cpp), занятость ячейки и зазоры |
| `rackscan/guidance.py`, `scanner.py` | команды наведения и автомат сканирования ячейки |
| `rackscan/evidence.py`, `overlay.py` | фото-доказательства, журнал, пометки на кадре |
| `rackscan/wms/` | эмулятор склада, сверка, HTTP-сервис в стиле 1С, клиент 1С, OData |
| `rackscan/server.py`, `web/` | сервер и пульт оператора (трансляция MJPEG) |
| `rackscan/sources.py`, `sensors.py` | камера Pi / USB / синтетика; протокол сенсорной головки ESP32 |
| `rackscan/synth.py`, `selftest.py` | синтетический стеллаж и самопроверка в замкнутом цикле |
| `rackscan/carrier.py` | шлюз безопасности для будущего дрона: какие уставки запрещено исполнять |
| `firmware/` | прошивка ESP32 (MPU-6050 + VL53L1X + WS2812B) |
| `onec/` | шаблон HTTP-сервиса для расширения конфигурации 1С (не проверен в базе) |
| `deploy/`, `config/` | установка на Raspberry Pi OS, автозапуск, примеры настроек |
| `docs/` | документация: исходники Markdown, рисунки, готовые PDF в `docs/pdf/` |

## Что проверено, а что нет

- Проверено на ПК: весь конвейер на синтетической сцене (18 ячеек, все виды исходов), 88 автотестов,
  живой запуск сервера и пульта.
- **Не проверено на железе:** `PiCameraSource` (Picamera2), прошивка ESP32, `deploy/install_pi.sh`.
- **Не проверено с настоящей 1С:WMS:** клиент работает с эмулятором и поддельным OData-сервером;
  имена объектов конфигурации 1С нужно взять из её метаданных.
- Занятость без эталона пустых ячеек — грубая эвристика по цвету картона; на реальном стенде
  снимите эталоны (`python -m rackscan calibrate-empty`) или подключите дальномер.

- Документы оформлены с учётом ГОСТ, но не проходили нормоконтроль; обозначения РСКН.… условные.
  Статус основных стандартов сверен по справочным базам 13.11.2026, остальные указаны по памяти.
- Цены комплектующих — по выдаче поисковой системы и оценкам; перед заказом проверить у продавца.
