# SIM-09: виртуальный облёт — оптика, смаз и точность позы против качества инвентаризации

Весь конвейер без Gazebo и ROS: план облёта → рендер кадров боковых камер 12 Мп по модели пинхол
(Gao & Zhang, гл. 4) с текстурами этикеток из генератора → zxing-cpp → привязка к ячейке по позе
(`association.face_point_in_warehouse`) → `SortieRecorder` → метрики чтения → сверка с WMS.

Рендер учитывает: разрешение на фасаде (текстура сжимается усреднением по площади, как пиксель
интегрирует свет), смаз от движения (скорость × выдержка), размытие оптики (σ = 0.6 px), шум сенсора.

**Условия:** 1 проход × 2 ряда × 10 секций × 4 яруса × 3 места (240 ячеек), занятость 80%, 3% ошибок
в WMS; этикетки SSCC A6 (GS1-128) и адресные 100×50 мм на балках; скорость пролёта 0.4 м/с,
выдержка 1 мс, дрон на оси прохода 3 м (1.5 м до фасада), `min_z` = 0.5 м.
Запуск: `python research/virtual_flight/run.py --workers 9` (≈ 10 мин на 12 ядрах).

## Выводы для проекта

1. **Расчёт оптики подтверждён.** Широкий объектив 50° при модуле 0.5 мм даёт 1.45 px на модуль —
   читается 8% этикеток. Объектив 12 мм (2.6 px на модуль) — 100%. Крупный модуль 0.8 мм «спасает»
   широкий объектив (97%). → Выбор камеры определяется **модулем реальных этикеток** (BIZ-06).
2. **Портретная установка камер** даёт адресные этикетки в кадре без потери производительности:
   180 чтений, все на своих местах (ADR-11). В альбомной установке адресные этикетки в кадр не попадают.
3. **Смаз — жёсткое ограничение.** Выдержка 3 мс при 0.4 м/с (смаз 1.2 мм ≈ 2.4 модуля) — 0% чтения.
   1 мс (≈ 0.8 модуля) — 100%. → Выдержка ≤ 1 мс при 0.4 м/с, значит, нужна **LED-подсветка со стробом**
   (PER-04). Прикидка «смаз ≤ 0.5 модуля» из `optics` консервативна: zxing выдерживает ≈ 0.8.
4. **Stop-and-scan не нужен**, если выдержка короткая (F = C) → непрерывный режим, производительность выше.
5. **Точность позы → точность инвентаризации (количественная связь для диплома).** До 15 см ошибки позы
   привязка к ячейке (ширина места 0.9 м) не страдает. При 30 см + 1° курса — 13% паллет приписаны
   чужой ячейке. Маркеры только на торцах дают 30–74 см в середине прохода (`research/landmark_ekf`) —
   этого **недостаточно** для надёжной привязки. Локализация по адресным этикеткам (2–6 см) даёт запас.
6. **Адресные этикетки «измеряют» ошибку позы:** их невязка растёт вместе с ошибкой
   (0.2 → 4.3 → 12.9 → 25.7 см). В наблюдениях есть информация для коррекции — на этом стоит LOC-11.

## Ограничения (что даст только реальный стенд PER-03)

Этикетки плоские и чистые, нет бликов плёнки, неравномерного света, rolling shutter, расфокуса по глубине;
zxing работает по идеальным текстурам. Реальный read rate будет ниже — эти цифры задают верхнюю
границу и **сравнение конфигураций между собой**, а не абсолютный прогноз.
