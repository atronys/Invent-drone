# MIS-07: планирование вылетов — жадный метод против точного решения

Задача 1 главы 2 (`docs/thesis/chapter2_model_draft.md`): разбить пролёты на вылеты от дока и обратно
(каждый не длиннее бюджета АКБ), минимизируя число вылетов (замен АКБ), затем суммарное время. NP-трудна,
поэтому на борту — эвристика; здесь она сравнивается с точным решением на малых складах.

- **Точное решение** (`exact.py`): Хелд–Карп по подмножествам пролётов (порядок и направление каждого),
  затем оптимальное разбиение на вылеты по подмножествам. Модель времени та же, что у планировщика.
- **Жадный «змейкой»**: пролёты по порядку, вылет заполняется, пока хватает АКБ.
- **Жадный + перебор** (`coverage.plan(optimize=True)`, по умолчанию): покоординатный перебор порядка
  проходов, направления входа и порядка ярусов с той же упаковкой; «змейка» входит в перебор — не хуже её.

**Выводы для ВКР:** по главному критерию — числу вылетов (замен АКБ) — жадный метод во всех случаях
совпал с оптимумом. По времени проигрыш «змейки» до 15% — там, где в проходе нечётное число пролётов
и дрон выходит из дальнего конца. Дешёвый перебор раскладки сокращает разрыв примерно вдвое (не более 8%).
Остаток — от перестановок пролётов между проходами внутри вылета; для реальных складов (сотни пролётов)
точный метод неприменим, следующий шаг — метаэвристика (ALNS, как в статье V) на тех же моделях.
